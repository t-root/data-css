Viết giao diện bằng thuộc tính data-css

Khai báo style ngay trên HTML với cú pháp group[key:value]. Runtime biên dịch thành class CSS, hỗ trợ responsive, pseudo-class, pseudo-element và DOM động.

Xem ví dụ → $ initDataCss()
index.html 
<button
  data-css="box[p:12px_20px|radius:10px]
            text[cl:#e2e8f0|bold]"
  data-pc-hover="box[shadow:0_0_24px_#22d3ee]">
  Deploy
</button>

→ CSS được sinh ra

.x7f3k { padding: 12px 20px; border-radius: 10px;
         color: #e2e8f0; font-weight: bold; }
.x7f3k:hover { box-shadow: 0 0 24px #22d3ee; }

01 · Typography

Kiểu chữ

Nhóm text[...] điều khiển màu, cỡ chữ, độ đậm, biến đổi và căn lề.

Text styles

Văn bản thường text[size:16px]
Bold uppercase text[bold|uppercase]
italic và capitalize text[italic|capitalize]
Gạch chân neon text[underline|decorationColor]
GLOW_TEXT text[shadow:0_0_18px_...]
Gradient text box[bgClip:text]

Text alignment

text[left]

text[center]

text[right]

text[justify] — đoạn văn được căn đều hai bên, khoảng cách giữa các từ tự giãn để lấp đầy chiều rộng khung chứa.
